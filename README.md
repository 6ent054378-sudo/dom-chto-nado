# Дом что надо — лендинг строительной компании

Одностраничный сайт (long-scroll, 22 блока) для компании **Дом что надо** — строительство домов из газобетона под ключ в Москве и Московской области.

Дизайн полностью воссоздан по референсу `desrep` (папка `../../../../../02_orders/website/demonstration/demos/desrep`): та же сетка, типографика Montserrat, тёмно-зелёная база, радиусы, отступы, анимации, поведение слайдеров, модалок и квиза. Отличия — палитра акцента, логотип и весь контент.

## Структура

```
index.html                 — главная (22 блока)
social.html                — страница соцсетей (фейковая, но рабочая: по ней ведут все иконки)
send.js                    — отправка заявок
vercel.json                — кэш-заголовки для Vercel
assets/
  css/style.min.css        — базовые стили референса (не трогать без нужды)
  css/brand.css            — переопределения бренда: акцент, логотип, градиенты, карта, аватары
  js/app.min.js            — библиотеки референса (слайдеры, модалки, квиз, Яндекс.Карты)
  fonts/                   — Montserrat (Regular / Medium / SemiBold / Bold)
  img/                     — изображения
  projects/                — галереи типовых проектов (по папке на проект)
_build/                    — исходники сборки (см. _build/README.md)
```

Порядок блоков: первый экран → о компании → состав дома → объекты → этапы → квиз → типовые проекты → комплектации → 3D-визуализации → проектная документация → материалы → стандарты → галерея → деньги/сроки/качество/сервис → сроки → отзывы → районы → прозрачность → цифровой контроль → команда → выставочный дом → контакты.

### Что заменить перед запуском

1. **Телефон, e-mail, адрес, ИНН, ОГРН** — в `index.html` (шапка, подвал, раздел контактов, политика) и в `social.html`.
2. **Ссылки на соцсети** — в `index.html` (`./social.html#telegram`, `#max`, `#vk`, `#instagram`) заменить на реальные аккаунты.
3. **Ссылки в `social.html`** (`Открыть канал →`, `Написать в MAX →` и т. д.) — сейчас ведут на якоря этой же страницы.

## Что настроить

1. **Отправка заявок** — `send.js`, константа `WEBHOOK_URL`. Пока она пустая, сайт работает в демо-режиме: заявка собирается, показывается экран «Спасибо», но никуда не уходит (в консоль). JSON нагрузки: `name, phone, channel, from, answers, utm, page, sentAt`.
2. **Яндекс.Карты** — `index.html`, `window.IdealHomeYandexMapsKey` (API-ключ). Без ключа показывается стилизованная заглушка с адресом и ссылкой на `social.html#map`. Координаты и адрес в `assets/js/app.min.js` (функция карты).
3. **Яндекс.Метрика** — `index.html`, `window.IdealHomeMetrikaId`. Пока ID = 0, счётчик вообще не загружается (внешних запросов нет).

Цены, сроки и гарантии в макете — рыночные ориентиры по Подмосковью, собранные из открытых прайсов конкурентов (АСД, Юржилсервис, hbtech, «Свои Дом», a3.house). Перед публикацией их нужно подтвердить договором:

- марка блока D400 по ГОСТ 31360, шов до 3 мм, армопояс по каждому этажу, СП 15.13330 / 17.13330 / 70.13330.

Любая гарантия и цена, не закреплённая в договоре, — рекламное обещание, которое оспорить можно.

## Изображения

Фотографии в `assets/img` и `assets/projects` — **временные**, взяты с сайтов конкурентов (a3.house) как демо-материал. Водяные знаки конкурентов удалены (фото с сайта «Юржилсервис» заменены целиком, рендеры очищены вручную), но права на снимки принадлежат их авторам.

**Перед запуском их нужно заменить на собственные:** реальные объекты, съёмка с объектов, планы проектов. Структура имён уже заведена, вёрстку менять не придётся:

- `a1obl`…`a6-6` — объекты (раздел «Наши объекты»);
- `assets/projects/<Название>/b1obl`…`b6-6` — типовые проекты;
- `sec2-*` — о компании; `sec27-*` — состав дома; `sec4-*` — комплектации;
- `sec5-*` — стандарты работ; `sec10-*` — материалы; `sec14-*` — районы;
- `k1`…`k14` — визуализации; `d1-*`…`d3-*` — документация;
- `e1`…`e17` — галерея; `h1`…`h12` — выставочный дом;
- `sec6-1`…`sec6-3` — команда (сейчас это аватары-инициалы, не портреты людей); `manager` — менеджер в модалке звонка;

**Людей на сайте нет:** вместо портретов команды и менеджера — аватары с инициалами в фирменных цветах. Заменяются на настоящие фото.

## Формы

Пять форм: квиз (2 копии — в секции и в модальном окне), форма в разделе «Цифровой контроль», форма обратного звонка, форма корректного номера. Все отправляются одним обработчиком `send.js`, маска телефона ставится библиотекой `app.min.js`.

## Проверено

- скриншот каждого из 22 блоков на 1440 и 390 px — вёрстка без горизонтального скролла, без наездов текста на фото, без «склейки слов» на мобильном;
- квиз проходится до формы, заявка уходит, показывается экран «Спасибо»;
- модалки (обратный звонок, форма, политика, куки) открываются и закрываются;
- консоль браузера без ошибок;
- все ссылки на изображения существуют, битых нет;
- внешних сетевых запросов нет (проверено через CDP);
- `app.min.js` и `send.js` проходят `node --check`.
