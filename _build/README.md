# _build — исходники сборки

Сайт собирается из отдельных файлов секций: так тексты правится в маленьких понятных кусках, а не в `index.html` на 280 КБ.

## Как пересобрать

```bash
cd _build
python3 build.py     # тексты секций 1–31 -> sections/*.html
python3 build2.py    # точечные правки (списки <li>, карточки)
python3 build3.py    # квиз
python3 build4.py    # глобальная замена реквизитов + подвал
python3 build5.py    # финальная зачистка текстов
python3 assemble.py  # сборка index.html из sections/*
```

`assemble.py` собирает `../index.html` в порядке блоков, заданном переменной `ORDER`, и проверяет баланс тегов.

**Правки в `index.html` после сборки будут перезаписаны.** Если нужно изменить текст — правьте соответствующий файл в `sections/` и пересобирайте. Правки, сделанные руками в `index.html` (например, в разделе `<head>` с ключами Метрики и Яндекс.Карт), при сборке сохраняются: `assemble.py` подставляет их заново.

## Файлы

| Файл | Что делает |
|---|---|
| `sections/HEAD.html` | `<head>`, шапка, открывающие `<main>` и `<div class="wrapper">` |
| `sections/N.html` | секция N (номер соответствует классу `section-N` в референсе desrep) |
| `sections/FOOTER.html` | подвал, модальные окна, cookie-баннер, подключение скриптов |
| `ed.py` | хелперы регулярных замен |
| `build*.py` | последовательные проходы замены текстов |
| `assemble.py` | финальная сборка `index.html` |
| `prep_final.py` | генерация недостающих изображений из пула |
| `clean_wm2.py` | удаление водяных знаков с чужих фото (диффузионное заполнение) |

## Осторожно

Секции `11`, `13`, `17`, `18`, `19`, `20`, `21`, `25`, `9` остались в папке, но **не входят** в сборку — они вырезаны из референса (мебель, текстиль, производственная площадка, командные обложки). Удалять их не нужно: они пригодятся, если клиент захочет вернуть блок.

Перед сборкой проверьте, что `sections/` — актуальная версия: скрипты правили файлы на месте, повторный запуск `build.py` применит замены повторно (все они идемпотентны — ищут уже заменённый текст и ничего не делают).
